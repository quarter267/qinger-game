# 青耳纪元：逆世归墟者

3D 开放世界动作游戏，基于 Three.js 开发。

## 简介

玩家扮演比尔，从繁华都市穿越到异世界青耳，在青耳村起步，斩妖除魔、锻造神兵、探索五域（青耳原野、赤沙雅丹、寒渊雪原、幽暗古林、熔岩裂谷），最终挑战中央火山。

## 操作

- **WASD** 移动
- **鼠标** 视角
- **Shift** 奔跑
- **左键/空格** 攻击
- **E** 互动
- **F** 跳跃
- **V** 切换视角（第三人称背面/第一人称/正面）

## 技术

- Three.js (WebGL)
- 程序化地形生成（FBM 噪声）
- AABB 碰撞检测
- PBR 纹理混合
- 移动端虚拟摇杆
